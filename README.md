   Student Management System

A beginner-friendly java console application to manage student records using MariaDB.

   Features:-

1. Add a new student
2. View all students 
3. Search for a student
4. Update student details 
5. Delete a student 

   Technologies Used:-
 
1. Java 
2. MariaDB
3.JDBC (Java Database Connectivity)
4. Git and GitHub

    Database:-
Database name: student_management

Table name: students

Student records include ID, name, age, course, and phone number.

    What I Learned:-

1. Connecting Java with MariaDB using JDBC
2. Using SQL to manage student records
3. Using PreparedStatement for database operations
4. Using Git and GitHub to manage and share project code
